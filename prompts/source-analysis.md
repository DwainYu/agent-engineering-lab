# Source Analysis Prompt

分析我贴给你的这段 Agent 相关源码 / 文档。

要求：

1. 用 3 句话说明它解决的问题
2. 列出它的核心抽象（类 / 函数 / 数据结构），并说明每个抽象存在的理由
3. 找出"如果没有这个抽象，我会自己写出什么"——即最小等价实现
4. 指出它在生产环境中的假设（并发、状态存放位置、失败处理、可观测性）
5. 指出我作为学习者应该先复刻哪一部分，才能理解它的设计
6. 不要给我结论性的"best practice"，只给我可以验证的事实

最后告诉我：这段代码应该对应我知识库里的哪个 Concept，
以及它属于学习顺序的第几层。
