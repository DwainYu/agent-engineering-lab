## Q001

为什么 Workflow 不需要循环，而 Agent 一定需要？

Status: resolved

Created: 2026-09-09

Resolved: 2026-09-10

Related:

- agent
- agent-loop

**Answer**

Workflow 的步骤数量在我写代码时就已经知道了，所以控制流可以放在我的
`for` / `if` 里。Agent 的步骤数量取决于中间结果说了什么，所以这个分支必须搬进
模型的输出里 —— 而模型之外必须有东西负责一直走下去，直到模型不再开口要东西。

改变的是什么：我不再试图通过措辞去"让模型决定"，而是开始把退出判定当成一段我自己
拥有的 runtime 代码。
